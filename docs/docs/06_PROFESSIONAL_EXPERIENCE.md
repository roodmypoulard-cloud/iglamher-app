# Beauty Professional Experience

## Onboarding

Collect:
- Legal name
- Display/business name
- Email and phone
- Profile photo
- Bio
- Categories and specialties
- Years of experience
- Service area
- Studio address, if applicable
- Mobile-service radius
- Portfolio
- Services, durations, prices, add-ons
- Availability
- Cancellation policy
- Identity/business verification data
- Stripe Connect onboarding

Allow draft progress and resume later.

## Professional dashboard

Show:
- Today’s appointments
- Upcoming bookings
- New requests requiring action
- Weekly earnings
- Profile completion
- Recent messages
- Review summary
- Quick actions

## Calendar and availability

Support:
- Weekly recurring hours
- Date-specific overrides
- Time off
- Buffer before/after appointments
- Minimum notice
- Maximum booking window
- Service-specific durations
- Prevention of overlapping bookings
- Optional external calendar sync in a later phase

## Service management

A professional can:
- Create/edit/archive services
- Assign category
- Set duration and price
- Add deposit requirements
- Set travel fee rules
- Add add-ons
- Upload service images
- Set service location type
- Control instant-booking eligibility

## Booking management

Actions:
- Accept or decline when manual approval is enabled
- Message customer
- Request reschedule
- Mark arrived/in progress/completed
- Report no-show
- Issue approved refund through platform rules

## Earnings

Show:
- Gross booking value
- Platform fee
- Stripe processing
- Adjustments/refunds
- Net earnings
- Pending balance
- Paid balance
- Payout history

Never label gross revenue as professional earnings.
