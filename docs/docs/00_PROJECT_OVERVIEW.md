# Project Overview

## Product promise

Book trusted beauty professionals anytime, anywhere, without the friction of social-media DMs, unclear prices, or unreliable scheduling.

## Customer problem

Beauty customers commonly struggle with fragmented discovery, uncertain availability, hidden add-on costs, inconsistent quality signals, and slow manual booking.

## Professional problem

Independent professionals need qualified leads, reliable deposits, calendar control, service management, customer communication, reviews, and payout visibility.

## Product principles

- Luxury without confusion
- Fast booking with transparent totals
- Trust before conversion
- Mobile-first, thumb-friendly interactions
- Strong photography with restrained decoration
- Clear cancellation and payment policies
- Marketplace neutrality: iGlamHer enables transactions but professionals control their services and schedules

## Initial service categories

- Hair
- Makeup
- Lashes
- Personal styling

The data model must allow new categories such as nails, brows, skincare, barbering, and bridal packages without schema redesign.

## User roles

- Guest
- Customer
- Beauty professional
- Admin
- Support agent

## MVP success metrics

- Search-to-profile conversion
- Profile-to-booking conversion
- Booking completion rate
- Cancellation rate
- Repeat booking rate
- Professional activation rate
- Average booking value
- Time from search to confirmed booking
