## Marketplace components

### ProfessionalCard

Contains:
- Profile image
- Display name
- Primary specialty
- Rating and review count
- Starting price where useful
- Distance or service area
- Verified indicator
- Favorite action
- Next available date, optional

Variants:
- Compact list
- Grid
- Featured

### ServiceCard

Contains:
- Service name
- Duration
- Price
- Short description
- Delivery type: at studio, mobile, or both
- Select action

### CategoryCard

Contains:
- Editorial image
- Category name
- Short supporting copy
- Link

### ReviewCard

Contains:
- Reviewer name/avatar
- Rating
- Date
- Service booked
- Review body
- Professional response, optional

### BookingSummary

Contains:
- Professional
- Service
- Appointment date/time
- Address or location type
- Base price
- Add-ons
- Taxes
- Platform/service fee
- Deposit or amount due now
- Remaining amount, if applicable
- Cancellation policy

## Buttons

- Primary blush fill
- Secondary rose-gold outline
- Tertiary text
- Destructive
- Icon button

Minimum touch target: 44×44px.

## Cards

Cards must have clear hierarchy, subtle borders, 16px radius, and no excessive gradients.
