# Admin and Operations

## Admin dashboard

Key cards:
- Gross booking value
- Net platform revenue
- Confirmed bookings
- Active customers
- Active professionals
- Professional approval queue
- Refunds and disputes
- Cancellation rate

## Professional moderation

Admin can:
- Review applications
- Approve, reject, or request more information
- Suspend/reactivate profiles
- Add verification badges
- Review portfolio and identity status
- View policy violations

## Booking support

Admin can:
- Search any booking
- View status history
- View payment and payout references
- Add internal notes
- Apply controlled status changes
- Issue full or partial refunds
- Flag suspicious behavior

Every sensitive admin action must be logged.

## Content management

Manage:
- Categories
- Homepage featured professionals
- Promotional banners
- FAQs
- Legal-policy version references
- Help-center articles

## Role-based access

Suggested roles:
- Super admin
- Operations
- Support
- Finance
- Content manager

Use least privilege.
